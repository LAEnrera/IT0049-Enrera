# Tasks for Today Management System

A CodeIgniter 4 task-management application developed for IT0049 Technical Summative Assessment 1.

## Features

- Welcome page showing only today's tasks
- Complete task list showing all tasks ordered by date
- Profile page showing one demo user
- About page identifying the developer
- MySQL database integration using CodeIgniter models
- Date-based task filtering

## Pages

- `/` - Tasks for Today
- `/tasks` - Complete Task List
- `/profile` - User Profile
- `/about` - About the Developer

## Database Setup

1. Create a MySQL database named `tsa1_tasks`.
2. Import the `tsa1_tasks.sql` file into the database.
3. Configure the database connection in the `.env` file.
4. Make sure Apache and MySQL are running.
5. Open the application at:
http://localhost/IT0049-Enrera/TSA1/public/
